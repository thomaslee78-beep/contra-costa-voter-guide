# Contra Costa Voter Guide — GitHub Pages PWA

1. Create a **new public repository** on GitHub (e.g. `contra-costa-voter-guide`).
2. Upload the **contents of this folder** to the repository **root** (not the containing folder): `index.html`, `manifest.webmanifest`, `sw.js`, `icon-192.png`, `icon-512.png`.
3. Open repository **Settings → Pages → Build and deployment**. Set **Source: Deploy from a branch**; branch **main**, folder **/(root)**, then Save.
4. Open `https://YOUR-USERNAME.github.io/contra-costa-voter-guide/` once deployment completes.
5. On iPhone: Safari → Share → Add to Home Screen → Open as Web App → Add.

Offline access: load the published site once while online. Notes and selections are saved locally in browser storage; **they do not automatically sync across devices or across Safari and the Home Screen app**. Export notes before clearing browser data or changing deployments.

This is a static research guide; verify ballot/candidate information from official election authorities before voting. GitHub Pages sites are public; never commit personal notes or confidential information.
